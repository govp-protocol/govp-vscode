## English — source listing

**Short description**

Create, verify, and prepare GOVP evidence in VS Code, locally by default and without requiring an account, network connection, or MCP.

**Highlights**

- Signed Ed25519 local receipts stored in the workspace, with the private key protected by VS Code SecretStorage.
- Separate L0 integrity, L1 domain attribution and L2 current-trust results.
- Optional provider-bound MCP workflow with native VS Code OAuth handling.
- Digest-bound bundle review and explicit human confirmation before isolated, non-overwriting installation.
- No extension telemetry and no remote endpoint configured by default.

GOVP results are technical evidence, not legal certification, regulatory approval or proof that a declared event was truthful. Optional hosted and third-party providers have their own terms and privacy notices.

**Kurzbeschreibung**

GOVP-Nachweise in VS Code erstellen, prüfen und vorbereiten – standardmäßig lokal und ohne erforderliches Konto, Netzwerk oder MCP.
