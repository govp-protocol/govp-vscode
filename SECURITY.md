# Security policy

La versión mantenida es la `0.3.x`. Reporta vulnerabilidades de forma privada mediante la pestaña **Security** del repositorio `govp-protocol/govp-vscode`. No abras una incidencia pública con secretos, claves, tokens o exploits funcionales.

Incluye versión de VS Code y de la extensión, sistema operativo, pasos mínimos y la huella del artefacto afectado. El equipo confirmará recepción, evaluará impacto y coordinará corrección y divulgación.

La extensión no solicita claves privadas de dominio. La identidad local reside en SecretStorage. No incluyas su contenido en un informe.
